## 기준 시나리오

`npm run simulate -- --benchmarks`는 로봇 1대, 양방향 공유 통로, 충전 경쟁, 유한 버퍼 포화, 부품 보충 후 조립, 설비 고장 후 재개를 실행합니다. 자동 검증에서 각 기대 결과를 별도로 대조합니다.

SimPy 기본 예제(시드 42, 1,800초)는 **완제품 6개·운송 18건**이며 충전·대기·버퍼 정지·자재 부족이 실제 이벤트로 발생합니다. 이전 개발 중 TypeScript 엔진의 7개·19건과 구분합니다. 현재 TypeScript DES 엔진은 제거했으며 Python 난수 흐름과 엔진 버전을 결과에 기록합니다.

제공 수직 예제는 6단 구조 높이 2.699 m, 첫 선반 0.15 m, 운송물 0.3 m, 빔 0.05 m, 인출 여유 0.07 m, 공간 3 m, 천장 이격 0.3 m입니다. 실제 피치 약 0.424833 m와 상부 빔을 포함한 천장 조건을 확인합니다. 이는 실제 장비 사양이 아닌 제공된 예제 가정입니다.

## 재사용·배포의 경계

`uv sync --frozen`과 `npm ci`로 잠금 파일 설치를 확인합니다. 현재 인스턴스의 실행과 환경 설정 저장은 검증하지만, 인터넷 공개 배포·환경 Publish·새 작업에서 스냅샷 복원은 별도이며 수행했다고 주장하지 않습니다. CAD/OCR 자동 전사, 실제 로봇 사양 적합성, 실장비 처리량·안전·구조 검증은 미실행입니다.
