# 도면에서 3D 공간·적재 검토까지

웹 우선 사용과 도면/PDF·편집 UI 통합을 위해 **Three.js**를 선택했습니다. DES는 Python SimPy 서버로 분리하고 Three.js는 상태를 표시하는 데만 사용합니다. 화면이나 3D 프레임 수는 계산 결과에 영향을 주지 않습니다.

## Three.js와 Godot 선택

| 기준 | Three.js | Godot |
| --- | --- | --- |
| 브라우저의 PDF·폼·표·파일 편집 통합 | 기존 React·DOM과 같은 애플리케이션에서 구성 | 엔진 UI와 웹 UI 사이 별도 연동 필요 |
| 배포 | 정적 웹 자산으로 제공 | 웹 내보내기 및 엔진 런타임 필요 |
| 창고/랙 치수·배치 검토 | 필요한 기하·표시를 직접 구성하기 적합 | 가능하지만 이 범위에서는 엔진 기능이 많이 남음 |
| 독립 실행형·게임 물리·풍부한 장면 편집 | 별도 도구 선택 필요 | 강점 |

현재 선택은 물류 운영 DES와 웹 기반 사전 공간 검토에 맞춘 것입니다. 향후 실감형 장면이나 독립 실행형이 필요하면 같은 모델·이벤트 결과를 별도 Godot 렌더러에서 사용할 수 있습니다.

## 작업 순서와 확인 책임

1. **고객 원자료 접수:** PNG/JPG 또는 PDF를 브라우저 안에서 읽습니다. PDF는 페이지를 선택해 렌더링합니다. 원본 파일을 외부 서비스로 전송하지 않습니다. 파일명·형식·페이지와 렌더된 이미지를 프로젝트에 보존합니다. 원본 PDF 자체는 별도 보관하세요.
2. **축척과 최초 MAP 전사:** 도면 위 두 점 사이의 픽셀 거리에 알려진 실제 거리(m)를 대응합니다. 이 축척의 이미지가 2D 편집 화면에 표시됩니다. 경계·벽·기둥·통로·노드·공정 인계 위치를 사용자가 전사합니다. PDF의 추출 가능한 치수 문구는 참고 후보이며 자동 확정값이 아닙니다. 래스터 OCR, CAD 의미 추출, 자동 벽/공간 인식은 후속 범위입니다.
3. **치수·높이 검증:** 건물의 유효 폭·깊이·장애물·최저 유효 높이를 실측 또는 승인 도면에 대조합니다. 축척, 건물, 로봇 데이터시트, 랙·적재물 조건을 각각 확인하고 근거를 적습니다. 평면 도면만으로 유효 높이를 추정하지 않습니다. 도면 여백·여러 건물이 있을 수 있어 이미지 전체 폭을 건물 폭이라고 자동 가정하지 않습니다.
4. **5단/6단 적재 비교:** 아래 식과 하중·높이·피치 조건을 비교합니다. 미입력 또는 확인되지 않은 값이 있으면 검토 필요 상태로 남습니다. 수치가 한계를 넘으면 근거 확인 여부와 관계없이 불가 사유를 표시합니다.
5. **자동 배치 후보:** 로봇 폭·길이·필요 통로 폭을 입력한 뒤 직사각형 영역, 경계 여유, 횡단 통로, 기존 설비·장애물 제외 영역을 적용합니다. 두 방향의 격자 후보를 비교하는 결정론적 휴리스틱입니다. 전역 최적해, 실제 주행 가능성 또는 공학적 안전 승인을 뜻하지 않습니다.
6. **2D·3D 검토 및 DES 연결:** 생성한 랙 후보를 3D에서 높이·상부 여유와 함께 보고, 명시적 적용 버튼으로 2D 배치 객체로 전사할 수 있습니다. 운송 노드·통로·인계 위치·버퍼 및 운송규칙을 구성한 뒤 DES로 운영 처리량을 검토합니다. 배치 객체만 추가하면 자동으로 운송 업무가 생성되는 것은 아닙니다.

## CTU 랙 높이 계산

단수 N, 첫 선반 인계면 높이 h₀, 단간 피치 p, 적재물 높이 hL, 상단 여유 c일 때:

```text
최상단 선반 인계면 = h₀ + (N − 1) × p
최상단 적재물 높이 = 최상단 선반 인계면 + hL
랙 구조 총높이 = h₀ + N × p (마지막 단 위 상부 빔 포함)
필요 건물 유효 높이 = 랙 구조 총높이 + c
필요 로봇 인계 높이 = 최상단 선반 인계면 + 인출/인계 여유
```

단간 피치는 적재물 높이+인출 여유+빔 두께 이상이어야 합니다. 구조 총높이를 고정하면 피치를 (총높이−첫 선반 높이)/단수로 역산합니다. 적재물 중량은 선반 허용하중과 로봇 취급중량을 각각 만족해야 합니다. 모든 값은 m·kg를 사용합니다. 보강재, 보/기둥, 소방, 스프링클러, 바닥 내하중, 앵커, 처짐·내진, 적재물 전도, 장비 제조사의 인계·간섭 조건은 이 기본 산술 검토와 별도입니다.

CTU는 실제 제조사의 최대 인계 높이와 하중 조건이 필요합니다. 저상형 로봇과 팔레트 AMR은 바닥 운송이 가능하더라도 고단 랙을 직접 취급한다고 가정하지 않습니다. 외부 리프트·컨베이어·지게차 등의 인계 설계가 없으면 해당 고단 운영 적합성을 확정하지 않습니다.

로봇 실제 바닥면 사양은 추후 제공 예정이므로 초기 입력은 비워 두었습니다. 예제 가정을 불러오는 동작은 검토 과정을 보여 주는 용도이며 확인 상태를 자동 설정하지 않습니다. 데이터 변경은 관련 확인 상태를 해제합니다. `verified` 배치 상태는 **입력 근거 확인을 마친 기하 배치 후보**를 뜻하며 설비 안전 인증이 아닙니다.

## 초기 배치 모델의 범위

영역은 로컬 원점 (0,0)의 직사각형 창고입니다. 장방형 랙 베이의 배치 방향 0°/90°, 통로, 경계 여유와 제외 장애물의 보수적 외곽 직사각형을 사용합니다. 비정형 외벽, 기둥 보의 높이별 간섭, 출입구와 피난/소방 구역, 회전 스윕 영역, 인계 위치 접근성, 랙의 구조 상세 및 물류 비용의 다목적 최적화는 후속입니다. 실제 현장 적용 전에는 이 추가 조건과 제조사 도면을 확인해야 합니다.
