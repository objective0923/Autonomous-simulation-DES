# 고객 · 시나리오 관리

초기 화면에서 **고객 이름 / 시나리오 이름**만 입력해 만듭니다. 새 시나리오는 실행 가능한 예제 운영 모델을 바탕으로 시작하며, 실제 도면·로봇 사양을 확인한 프로젝트라는 뜻은 아닙니다.

## 순서대로 입력

1. **도면:** PNG/JPG/PDF를 선택합니다. 도면이 아직 없으면 건너뛸 수 있습니다. 축척은 확인 근거와 함께 나중에 보정합니다.
2. **공간:** 건물 유효 폭·깊이·높이를 입력합니다.
3. **로봇:** 종류·외형·통로·인계 가능 높이를 입력합니다. 모르는 값은 비워 두며 예제 가정을 실제 사양으로 확정하지 않습니다.
4. **랙:** 단수·적재물·선반 조건을 설정합니다. 빔·여유·하중 등은 고급 설정에서 조정합니다.
5. **높이 검토:** 선택 단수의 결과와 로봇·랙 측면도를 확인합니다. 대안 비교와 단별 표도 사용할 수 있습니다.
6. **배치:** 기하 배치 후보를 3D로 확인하고 운영 모델 편집·시뮬레이션으로 이동합니다.

이전/다음으로 이동해도 입력을 유지합니다. 미확인 상태와 누락 사양을 알려주되 초안 저장은 허용합니다. 의미상 잘못된 값과 모델 오류는 수정해야 저장·실행할 수 있습니다.

## 저장·다시 열기

- 입력 변경은 잠시 후 자동 저장하며, 저장 중·저장됨·저장 실패 상태를 표시합니다. 저장 버튼으로 즉시 저장할 수도 있습니다.
- 시뮬레이션은 저장한 입력으로 실행하고, 해당 입력과 일치하는 최근 결과를 함께 보관합니다. 입력이 바뀌면 이전 결과를 최신 결과로 표시하지 않습니다.
- 저장함에서 고객별 시나리오를 검색·열기·복제합니다. 같은 고객에서 같은 시나리오 이름은 중복되지 않도록 안내합니다.
- 삭제는 확인 후 선택한 시나리오와 그 결과를 삭제합니다. 다른 고객·시나리오에는 영향을 주지 않습니다.
- 파일 내보내기는 별도 보관이나 다른 환경으로 전달할 때 사용합니다. 이전 버전의 브라우저 저장·JSON 입력도 고객 이름을 지정해 저장함으로 가져올 수 있습니다.

저장 위치는 이 프로그램을 실행하는 PC입니다. 여러 PC 사이 자동 동기화나 다중 사용자 계정 공유 기능은 제공하지 않습니다.

## 백업

Python 기본 제공 SQLite를 사용하므로 DB 서버나 계정 설정은 필요하지 않습니다. 데이터는 저장소의 `data/` 폴더에 보관하며 Git에 올리지 않습니다. 백업·이전 시에는 프로그램을 종료한 뒤 **data 폴더 전체**를 복사하세요. 코드를 업데이트할 때 이 폴더를 지우지 마세요.

다른 저장 위치가 필요한 경우에만 서버의 `CROIS_DATA_DIR`을 지정할 수 있습니다. 일반 사용에서는 설정할 필요가 없습니다. 자동 검증은 임시 저장 폴더를 사용해 실제 고객 데이터를 수정하지 않습니다.
